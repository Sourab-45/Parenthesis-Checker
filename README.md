# Parenthesis Checker – Matching and Correction System

## Project Description
A Java-based Parenthesis Matching and Correction System that uses the Stack data structure, implemented manually using arrays, to check and correct bracket expressions.

## Features
- Checks matching of `()`, `{}`, and `[]`.
- Detects missing, extra, and mismatched brackets.
- Displays bracket error information and positions where available.
- Automatically corrects common bracket errors.
- Ignores brackets inside double-quoted strings and single-quoted characters.
- Ignores brackets inside single-line and multiline comments.
- Validates empty input.
- Provides an interactive menu for checking, correcting, and exiting.

## Technologies Used
- Java
- Visual Studio Code
- Stack Data Structure
- Arrays

## How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Compile the Java program:

   `javac ParenthesisChecker.java`

5. Run the program:

   `java ParenthesisChecker`

## Menu Options
1. Check Expression
2. Correct Expression
3. Exit
